# 9. Architecture decisions

| ADR | Decision |
| :--- | :--- |
| [0001](../adr/0001-sample-timestamps-are-seconds.md) | Sample timestamps are seconds in both directions |
| [0002](../adr/0002-swift-package-manager-only.md) | Swift Package Manager only |
| [0003](../adr/0003-one-event-channel-per-subscription.md) | One event channel per live subscription |
| [0004](../adr/0004-static-api-mocked-through-channels.md) | Static API, mocked through its channels |

The JSON contract itself is decided by HealthKitReporter's [ADR 0004](https://github.com/kvs-coder/HealthKitReporter/blob/master/docs/adr/0004-contract-changes-for-the-next-major-release.md).
